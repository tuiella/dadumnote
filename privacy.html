다듬노트 개인정보 처리방침

시행일: 2026년 10월 6일 · 게시자: 스튜디오301

다듬노트(이하 "앱")는 사용자의 개인정보를 수집하지 않으며, 앱이 다루는 모든 데이터는 사용자의 컴퓨터 안에만 저장됩니다.

1. 수집하는 정보

앱은 이름, 이메일, 기기 식별자, 사용 기록 등 어떤 개인정보도 수집하거나 게시자의 서버로 전송하지 않습니다. 앱에는 광고, 분석(통계) 도구, 회원 가입 기능이 없습니다.

2. 앱이 저장하는 데이터

  • 원고와 연구 자료: 챕터, 참고문헌, 인용, 메모, 마인드맵, 연구자 정보, 버전 기록은 사용자가 고른 원고 폴더 안에 저장됩니다.
  • 앱 설정: 화면 설정과 최근 연 원고 폴더 목록은 사용자의 Windows 계정 안 앱 설정 폴더에 저장됩니다.
  • 사용자가 첨부한 PDF의 글자 인식(OCR)은 컴퓨터 안에서 처리되며 외부로 보내지 않습니다.

이 데이터는 사용자가 직접 지우거나 옮길 수 있으며, 앱을 제거해도 원고 폴더는 지워지지 않습니다.

3. 외부 서비스

  • OpenAI Codex 연결(선택): 사용자가 직접 연결을 누른 경우에만, 앱은 사용자의 컴퓨터에 있는 Codex 설정 파일에 로컬 연결 정보를 추가합니다. 이후 Codex가 원고를 읽거나 고치는 것은 사용자의 Codex 사용에 따르며, 그 데이터 처리는 OpenAI의 정책을 따릅니다.
  • GPT로 물어보기·LLM 입력: 앱은 프롬프트를 클립보드에 복사할 뿐, 직접 전송하지 않습니다. 사용자가 다른 서비스에 붙여넣은 내용은 그 서비스의 정책을 따릅니다.
  • 참고문헌의 웹 주소(DOI 등)를 누르면 기본 웹 브라우저가 열립니다.

4. 아동의 개인정보

앱은 어떤 연령의 사용자에게서도 개인정보를 수집하지 않습니다.
